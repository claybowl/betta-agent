# Donjon Agent 0.5.0 — Betta Agents

The chat interface becomes Betta Agents: a new look, pickers in place of typed menus, saved logins, and goal loops. The command (`donjon-agent`), package name and agent homes are unchanged.

## Included

- Betta Agents wordmark and the Magic City theme (gold, flamingo, teal), with a large animated startup banner on terminals 76 columns or wider. `/theme` switches themes; `DONJON_NO_MOTION=1` skips the animation.
- Command palette: typing `/` opens an arrow-key list with filtering and Tab completion.
- `/model`: a filterable picker over the runtime catalog. Models are marked live where the provider's own endpoint confirms them, free models are tagged, and providers without credentials are listed with what they need. Typed model refs are checked before they are saved, with suggestions for near misses.
- `/login` and `/logout`: paste a provider API key once, or sign in with a ChatGPT subscription. Logins are stored owner-only in `~/.donjon/credentials.json`. Environment variables still work.
- `/goal [--rounds N] [--budget USD] OBJECTIVE`: the agent keeps taking turns until it reports done or blocked, or a turn or spend limit stops it (default 8 turns, $2).
- Pickers for agents, skills, permissions, runtime and settings; a working spinner during turns.
- Skills: folded and multi-line descriptions are read correctly, and folders that are skipped are reported with the reason.
- Project icon in `assets/`.

## Upgrade and compatibility

No migration. Agent homes and execution state from 0.4.0 work unchanged. App settings saved with the old default purple theme move to Magic City once; `/theme purple` restores it. A new file, `~/.donjon/credentials.json`, appears only after the first `/login`.

Install the downloaded archive with `npm install -g ./donjon-agent-0.5.0.tgz` after verifying SHA256SUMS.

## Limitations

- ChatGPT subscription sign-in was verified up to the browser hand-off, not through a completed login.
- Claude Pro/Max subscription sign-in is not offered: Anthropic's terms reserve it for Claude Code and claude.ai. An Anthropic API key works.
- Saved logins are plain text in an owner-only file; there is no system keychain integration yet.
- NVIDIA, OpenCode and Z.ai models come from the runtime catalog and are not confirmed against a live endpoint.
- The interactive interface is not tested on Windows.
