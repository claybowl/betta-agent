# Donjon Agent 0.1.0

Initial standalone release of the local, stateful agent harness.

Includes portable Markdown memory, Git history, durable Pi execution, terminal chat, cancellation, request deduplication, and copy/continuation exports.

Requires Node 22.19+ and Git. Configure Ollama or provider credentials separately. Existing agent homes remain outside the application checkout and can be used directly. No memory migration is required.

Install the attached archive with `npm install -g ./donjon-agent-0.1.0.tgz`. Verify it against SHA256SUMS before sharing.

The Doer adapter remains in Doer. MCP, a desktop interface, and in-app settings are planned features; this release retains the terminal interface. Arbitrary external effects are not guaranteed exactly-once.
