# Donjon Agent 0.3.0

This release adds committed MemFS memory, deferred reference indexes, durable memory updates, conversation recall, reflection proposals, and an ASCII memory map.

## Included

- Immutable core memory per turn, restored after compaction; committed skills and indexed deferred references.
- Validated multi-file memory transactions with crash recovery, provenance, and stale-write protection.
- Memory status, search, history, revert, explicit Git sync, bundles, and history-preserving exports/imports.
- Bounded reflection with preview, apply, retry, conflict retention, and a headless command for orchestration.
- `/memory graph` and `/memory graph PATH` show committed files, explicit Markdown/wiki links, and backlinks.
- Optional `history_search` and `history_read` tools read a per-agent historical SQLite archive when present.

## Upgrade and compatibility

Back up the agent home before upgrading. Existing homes migrate memory on first use; source revisions remain in local memory Git history. Execution recovery and request deduplication remain supported. No paid model call is needed to migrate memory.

Install the downloaded archive with `npm install -g ./donjon-agent-0.3.0.tgz` after verifying SHA256SUMS.

## Limitations

The terminal graph is a text view with path commands, not an interactive arrow-key browser or an inferred semantic graph. Historical archive ingestion is currently a local preparation step, not a general import command; the optional state/history.sqlite archive is not included by agent exports and must be backed up separately. Older Letta layouts with assets or unsupported paths may require a staged import. Reflection cost ceilings are estimates. External shell/MCP effects cannot be guaranteed exactly-once. No desktop installer or automatic updater is included.

No personal agent memories, transcripts, credentials, or databases are included in this software release.
