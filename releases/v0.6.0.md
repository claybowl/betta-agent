# Betta Agents 0.6.0

- Adds the native Doer worker protocol and agent-scoped Doer work notes. Doer sends a run token and records usage for each heartbeat.
- Adds opt-in network, browser, and desktop connectivity controls.
- Bounds stalled model requests and improves tool output in the terminal.

Existing agent homes can be opened directly. This release requires no state migration. Browser and desktop integrations require the corresponding tools on the machine running Betta. Install the archive with Node 22.19 or later.
