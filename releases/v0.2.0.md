# Donjon Agent 0.2.0

Interactive chat now streams commands and output, supports Escape cancellation, and records action outcomes, including uncertain interruptions. Slash commands provide agent switching, settings, skills, and action history, with a new terminal theme and startup banner.

MCP connections support stdio and Streamable HTTP servers, tool discovery, and credentials supplied through environment variables. Per-agent settings control the working directory, tool permissions, model, and runtime behavior.

## Compatibility and upgrade

Existing agent homes work without migration. When no settings file exists, shell and file permissions inherit the existing `allowShell` setting; saved settings take precedence. Worker overrides retain precedence. Agent exports include settings with MCP connections disabled; continuation exports also carry action receipts. Back up agent homes before upgrading.

Install the release archive after checking SHA256SUMS. The Doer adapter still uses its own embedded runtime and is not upgraded by installing this package.

## Known limitations

Escape cancels the turn but cannot undo external effects. An unknown action outcome must be checked before retrying. Permissions control tools and do not provide an operating-system sandbox. MCP OAuth, legacy SSE, resource browsing, and prompt catalogs are not included. Skill loading is observable but does not guarantee model compliance.
